# Домашняя аптечка онлайн

Fullstack-приложение для учета домашних лекарств: сроки годности, список "отдать до срока" для передачи в приют.

## Стек
- **Frontend:** React + TypeScript + Vite
- **UI-библиотека:** MUI (Material UI)
- **Маршрутизация:** React Router
- **Backend:** (появится позже)
- **БД** (появится позже)

## Назначение приложения

Пользователь ведет учет домашней аптечки: добавляет лекарства, отслеживает сроки годности, формирует список препаратов для передачи в приют.

## Пользовательские сценарии

1. **Просмотр общего состояния аптечки** - сколько всего лекарств, у скольких истекает срок годности, сколько можно отдать в приют
2. **Просмотр списка лекарств** - отображение всех лекарств с пометкой, у кого скоро закончится срок годности и у кого уже истек, фильтрация по категориям и поиск по названию
3. **Добавление лекарства** - форма с названием, категорией, количеством таблеток и скроком годности.
4. **Список "отдать до срока"** - препараты, которые можно передать в приют
5. **Профиль пользователя** - данные текущего пользователя
